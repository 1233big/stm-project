01

电路和 C 语言基础

15 天线下

构建机器人硬件与底层控制的基石：掌握计算机组成、数模电与 C 语言编程，为复杂机器人系统打下坚实基础。

核心内容

计算机体系结构 内存 / CPU / 外设 数据表示 组合电路 模拟电路 数字电路 常见元器件 C 语言编程入门 数据结构与算法 编程调试技巧

阶段产出

硬件物理解层 + 控制层基础能读懂原理图与器件手册
02

单片机开发

25 天线下

深入机器人核心部件的“大脑”——单片机：掌握 GPIO、传感器、电机控制与通信，具备独立开发机器人基础硬件模块的能力。

核心内容

单片机工作原理与基本架构 GPIO 控制与配置 模拟信号采集与数字化 定时器与中断 常用传感器使用 电机控制 UART / I2C / SPI 电路设计软件使用 原理图设计 PCB 布局设计基础 能耗管理与优化

实战项目

蓝牙麦克纳姆轮底盘项目
03

AI Linux 应用开发

15 天线下

驾驭机器人常用的 Linux 系统，结合 AI 工具高效开发上层应用（感知、决策、控制逻辑），成为机器人领域复合型人才。

核心内容

Linux 命令行与文件管理 AI 辅助的应用程序开发 系统调用与库函数

实战项目

智能家居控制系统 工业 PLC 控制系统 智能车载系统 医疗设备上位机 机器狗测试系统
04

AI 嵌入式开发

20 天线下

精通机器人常用 ARM 处理器与 RTOS 实时操作系统，熟悉外设驱动、功耗优化，满足机器人对精确控制与实时响应的严苛要求。

核心内容

ARM Cortex-M 架构与指令集 STM32 / GD32 IDE 与工具链 外设驱动（GPIO / ADC / UART / I2C / SPI） 定时器与 PWM 生成 系统时钟配置与优化 中断管理与 ISR 编写 DMA 使用与配置 功耗管理（低功耗模式） RTOS 基本概念与使用 代码优化与调试技巧

实战项目

交互扩展板 + FreeRTOS 项目
05

蓝牙 WiFi 与 LVGL 开发

10 天线下

为机器人赋予“沟通”与“展示”能力：学习 GUI 设计与 LVGL 图形库，结合无线通信实现 HMI 与远程控制。

核心内容

LVGL 图形库与自定义控件 GUI 设计与用户体验 触摸屏输入与事件处理 蓝牙 BLE / Classic 配置与传输 WiFi 配置与网络通信 TCP/IP 协议栈基础 JSON / XML 数据编解码 MQTT 远程设备控制 安全性与数据加密 用户接口设计与测试

实战项目

安防摄像头 穿戴手表 感情陪伴助手 黑马深夜食堂后厨打印机
06

Linux 驱动开发

5 天线下

掌握为机器人定制硬件（特殊传感器、执行器）编写 Linux 驱动的核心技能，确保各部件被操作系统高效管理。

核心内容

系统调用与库函数 设备驱动结构与编写 Makefile / 构建系统 进程与多线程编程 Linux 调试工具 网络编程 Linux / 安卓 / 鸿蒙编译与裁剪

实战项目

设备驱动项目Linux 内核项目

🧭 学习路线图说明

  1. 电路和C语言基础：构建机器人硬件和底层控制的基石，掌握计算机组成、数模电及 C 语言编程，为复杂的机器人系统打下坚实基础。
  2. 单片机开发：深入机器人核心部件的“大脑”——单片机，掌握 GPIO、传感器、电机控制及通信，具备独立开发机器人基础硬件模块的能力。项目：蓝牙麦克纳姆轮底盘。
  3. AI Linux应用开发：驾驭机器人常用的 Linux 操作系统，结合 AI 工具高效开发机器人上层应用（如感知、决策、控制逻辑），成为机器人领域复合型人才。项目：智能家居、工业PLC、智能车载等。
  4. AI嵌入式开发：精通机器人常用 ARM 处理器及 RTOS 实时操作系统，熟悉外设驱动、功耗优化，满足机器人对精确控制与实时响应的严苛要求。项目：交互扩展板 + FreeRTOS。
  5. 蓝牙wifi和LVGL开发：为机器人赋予“沟通”与“展示”能力，学习 GUI 设计与 LVGL 图形库，结合无线通信技术实现机器人 HMI 与远程控制。项目：安防摄像头、穿戴手表等。
  6. Linux驱动开发：掌握为机器人定制硬件（如特殊传感器、执行器）编写 Linux 驱动的关键技能，确保机器人各部件能被操作系统高效管理。项目：设备驱动、Linux 内核。
  7. 具身智能机器人开发：融合大语言模型与机器人技术，学习模仿学习、强化学习等前沿 AI 算法，实现“大脑”与“身体”的协同，掌控机器人完成复杂任务，迈向 AI 驱动的智能机器人时代。项目：视觉机器人、MCP 机械臂。
  8. 毕业工作后冲高薪课程：通过 C++、高级 AI、机器人学、机器视觉等进阶课程，拓宽技术视野，深化专业技能，实现机器人工程师职业生涯的飞跃。
