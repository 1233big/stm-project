就业达标补充路线

原路线图解决的是「知识覆盖」。企业校招看的是「你能不能干活」。这份清单补的是课程没教的四块：笔试基本功、工程能力、自研项目、实习与竞赛证明。

起点：2026.11 大二上第 8 周 终点：2028.09 秋招 周期：约 22 个月
01

先看清：课程给你什么、不给你什么

80%

知识覆盖

从电路到 RTOS 的知识面完整，这是路线图最大的价值。

30%

工程能力

Git、Makefile、GDB、示波器、看 datasheet——课程默认你会。

20%

项目可信度

教学项目人人同款，面试问「为什么这样设计」就答不出。

0%

实习与竞赛

这两项在机器人/嵌入式校招里的权重，高于任何一门课。

02

七个补课模块

叠加在原路线图上并行推进

A

笔试基本功

每天 40 min
课程不教，但校招第一关就是笔试。这一块不过，后面全白搭。
  • C 深水区：指针与数组、函数指针、const/volatile/static、结构体对齐、位运算、大小端
  • 内存模型：栈 / 堆 / .data / .bss / 常量区，一个变量存在哪
  • 编译链接：预处理→编译→汇编→链接，读懂 .map 文件
  • 算法：链表、栈队列、哈希、二叉树、排序；LeetCode 目标 150 题
  • 嵌入式八股：启动流程、中断向量表、RTOS 调度、I2C/SPI/CAN 时序
B

工程能力

边做边学
入职第一个月就要用。学生和工程师的分水岭，几乎全在这里。
  • Git：分支、合并冲突、commit 规范；所有代码进仓库
  • 构建系统：手写 Makefile、CMake 基础、链接脚本 .ld
  • 调试：GDB + OpenOCD、断点/观察点、HardFault 定位到行号
  • 仪器：示波器、逻辑分析仪、可调电源限流、烙铁热风枪
  • 文档：README、原理图、BOM、测试记录——面试官会看
C

一个自研项目

6–12 周
这是简历上唯一能证明「你会干活」的东西。一个做深 > 五个跟教程敲的。
  • 从 0 开始：自己画板（嘉立创打样）、自己写固件、自己写上位机
  • 有真实约束：成本、功耗、体积、可靠性至少占一项
  • 有量化指标：能说「待机电流 42µA」「抓取成功率 85%」
  • 有取舍故事：为什么用 DMA 不用中断，为什么这个电阻选 10k
D

竞赛

2027 全年
机器人岗对竞赛的认可度≈半个实习，尤其是电赛国赛。
  • 全国大学生电子设计竞赛：2027 年是国赛年，8 月，最对口
  • 智能车竞赛：选题方向与嵌入式控制高度重合
  • RoboMaster：团队工程量大，简历亮点最强但耗时
  • 蓝桥杯嵌入式：个人赛，顺便练笔试手感
E

实习

2028.3–8
校招最硬的一张牌。有实习的本科生，简历直接进下一轮。
  • 2027.10 开始投：暑期实习提前批，提前半年
  • 目标：嵌入式软件 / 驱动 / 测试开发，优先有转正名额的
  • 大二暑假别空着：实验室、学长工作室、小厂项目都算
  • 实习中留下证据：需求文档、提交记录、上线数据
F

系统原理

大三上，约 40 h
只会调库的人，三年后会被淘汰；懂原理的人，能往上走。
  • 操作系统：进程/线程、调度、内存管理、同步与互斥
  • RTOS 原理：任务切换、优先级反转与继承、临界区
  • 数据结构：手写链表/环形缓冲区/状态机，别只会调库
  • 英语：能直接读 reference manual，不靠翻译
G

表达与包装

持续
同样一个项目，会讲的人拿到 offer，不会讲的人被当成"跟着做的"。
  • 简历一页：STAR 结构，每条都带数字
  • 三分钟讲项目：背景 → 我的方案 → 结果 → 踩坑
  • 复盘文档：每个项目写完就归档，秋招前直接复用
  • GitHub：有 README、有图、有测试记录的项目首页
03

两年落地节奏

蓝色=原课程，绿色=补充模块，橙色=里程碑

大二上（现在 → 2027.01）

约 10 周 + 寒假
课程阶段 1+2：电路与 C 语言、单片机（GPIO / 定时器 / 中断 / 通信 / PCB）
补充A 笔试 每天 40 min（C 深水区 + 50 题）；B 工程 把 Git、Makefile 用起来
里程碑寒假：亲手画一块最小系统板并打样点亮——从原理图到固件全自己来

大二下（2027.02 → 2027.06）

约 18 周
课程阶段 3+4：Linux 应用开发、STM32/GD32 外设驱动、DMA、RTOS
补充C 自研项目 立项并开工；D 竞赛 组队准备电赛（控制类方向）
里程碑进实验室 / 找到带队学长；自研项目做出第一个可运行的版本

大二暑假（2027.07 → 2027.08）

约 8 周
课程阶段 5：蓝牙 / WiFi / LVGL / MQTT，做一个带屏能联网的设备
补充D 竞赛：电赛国赛（8 月）全力冲
里程碑拿到一个省级以上奖项，简历第一行有了内容

大三上（2027.09 → 2028.01）

约 18 周
课程阶段 6：Linux 驱动做深（完整字符设备 + 设备树 + 一次真实 oops 调试）
补充F 系统原理；E 实习 10 月起投 2028 暑期实习；刷题到 150
里程碑自研项目结项并写完复盘文档；拿到第一份实习面试

大三下 + 暑假（2028.02 → 2028.08）

约 6 个月
课程阶段 7 具身智能当兴趣补充，不作为主攻方向
补充E 实习 全力争取转正；G 表达 整理项目与简历
里程碑一段 ≥2 个月的嵌入式实习——秋招最硬的一张牌

大四上（2028.09 → 2028.11）

秋招
课程阶段 8：C++ / SLAM / 点云，作为简历加分项，别当主菜
补充八股冲刺 + 项目复盘 + 模拟面试
里程碑投递 → 面试 → offer

无刷电机 FOC 驱动小板

★★★★☆
成本 ≈ 120 元 · 6–8 周
涉及技术

STM32 + ADC 注入采样 + PWM 死区 + 电流环 PI + 串口上位机在线调参

面试可讲

为什么用注入通道、死区时间怎么算、电流环带宽怎么调

验收：电机低速平稳无抖动，上位机能实时看三相电流波形

低功耗电池环境节点

★★★☆☆
成本 ≈ 80 元 · 4–6 周
涉及技术

STOP 模式 + RTC 唤醒 + DMA + LoRa/BLE 上报 + 功耗实测

面试可讲

每个 µA 花在哪、唤醒源怎么选、为什么不用中断轮询

验收：单节 18650 实测续航 ≥ 3 个月，待机电流 < 50 µA

桌面三轴机械臂 + 视觉抓取

★★★★★

06

三句大实话

别做课程收集者

把一门课学完，不如把一个项目做穿。面试官不问你上了几门课，只问你做过什么、卡住过什么、怎么出来的。

别等到大三才找组织

实验室、学长、竞赛队，越早进越好。有人带一年的效果，抵得上自己摸索两年。现在就去敲实验室的门。

别怕英文手册

Reference Manual 和 Datasheet 是这行的母语。硬着头皮读半年，你会发现自己不再需要任何中文教程。
