01

官方文档

第一手资料，永远优先

STM32 Reference Manual

必读

每个外设的寄存器定义、时序、工作模式。配寄存器时逐位对照，不要凭记忆。按型号查 RM 编号（如 RM0008 / RM0090）。

获取：ST 官网 → 对应型号 → Reference Manual（PDF）
www.st.com

STM32 Datasheet

必读

引脚定义、电气参数、绝对最大额定值、封装尺寸。算限流电阻、查 IO 最大电流就靠它。

获取：与 Reference Manual 在同一个产品页

FreeRTOS 官方文档

必读

任务、队列、信号量、内存管理的权威说明。API 用法看官方，比任何二手教程都准。

另见 GitHub 上的源码与例程
www.freertos.org

Linux 内核文档

进阶

驱动模型、设备树绑定、子系统文档。查 compatible 属性、GPIO/I2C 子系统的用法都在这里。

docs.kernel.org

ARM Cortex-M 架构手册

进阶

异常模型、NVIC、内存映射、指令集。想真正理解中断与栈，绕不开它。

www.arm.com

器件 Datasheet（传感器/芯片）

必读

每个 I2C/SPI 器件的寄存器表、时序要求、上电时序。调试总线问题时的唯一依据。

获取：立创商城 / 芯片厂商官网，搜型号 + datasheet

03

书单

四本打底，两本进阶，不必全买

《C 和指针》

M2 配套

指针与数组讲得最透的一本。做完书中例题，C 语言深水区就过了。

《C 陷阱与缺陷》

M2 配套

薄，但每一页都能救你一次。笔试里的坑大半来自这里。

《ARM Cortex-M3 权威指南》

M3 配套

中断、异常、栈、启动流程讲得最清楚。理解内核必读。

《Mastering STM32》

M3–M6

英文，但把外设原理和 HAL 用法结合得最好。适合当参考书。

《嵌入式 C 语言自我修养》

进阶

讲嵌入式里 C 的特殊用法与坑：位域、内存布局、编译优化。

《Linux 设备驱动程序》

M10

驱动开发的经典（LDD3）。版本偏老，但内核模型的思想没过时。

05

怎么读手册

这一节比前面所有资源都重要

  1. 先读目录，再看章节结构。Reference Manual 通常按「概述 → 功能描述 → 寄存器」组织，先建立地图。
  2. 只读你需要的那一节。不要从头读到尾——1000 页的手册，你只需要其中 20 页。
  3. 先看「功能框图」和「时序图」。图能在一分钟内让你明白这个外设的数据怎么流动。
  4. 再对照寄存器表逐位配置。每个位是什么意思、什么条件下有效，手册里都写了。看不懂英文就查单词，别跳。
  5. 写代码时把手册那页开着。配一个寄存器就核对一个，别凭记忆。这一步能省掉你 80% 的调试时间。
  6. 读到「Note / Caution」一定停下来。厂家专门标出来的，都是有人踩过的坑。
关于英文：手册是这行的母语。前三个月会慢，第四个月开始你会发现中文教程反而更绕。 建议：每遇到一个不认识的术语就记到笔记里，两个月就能积累出你自己的词汇表。
